# 🎓 Binalbagan Catholic College (BCC) - Official Website

Official website project for **Binalbagan Catholic College**, built with modern web technologies to showcase the institution, its programs, and services.

---

## 📌 Project Overview
This is the official website for Binalbagan Catholic College (BCC), designed to be responsive, fast, and easy to navigate for students, parents, visitors, and staff.

## ✨ Features
- ✅ **Responsive Design** — works perfectly on mobile, tablet, laptop, and desktop
- ✅ **Complete Sections** — Home, About Us, Academics, Admissions, News & Events, Contact Us
- ✅ **Smooth Navigation** — mobile-friendly menu, smooth scrolling between sections
- ✅ **Interactive Elements** — image sliders, buttons, hover effects
- ✅ **Functional Contact Form** — ready to receive messages
- ✅ **Clean & Modern Layout** — professional and easy to read

## 🛠️ Technologies Used
- **HTML5** — structure and content
- **CSS3** — styling, layout, colors, fonts, responsiveness
- **JavaScript** — interactivity, animations, navigation logic
